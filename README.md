# Passage Lab · 영어 지문 분석 및 내신 대비 학습 플랫폼

영어 지문 전체를 입력하면 Claude가 지문을 분석해 시험 대비 학습 자료를 만들어 주는 웹 서비스입니다.

## 주요 기능

| 메뉴 | 내용 |
| --- | --- |
| 1. 전체 분석 | 주제, 영어·한국어 제목, 요지, 주장·의도·목적, 키워드, 전체 번역, 한/영 요약, 문단별 핵심, 전개 방식, 논리 흐름, 주장과 근거, 글의 구조(단계별 흐름도), 핵심 문장, **문장 간 논리 관계도**(화살표 다이어그램) |
| 2. 문장별 분석 | 모든 문장의 직역/의역, 어순 끊어 읽기, 문장 성분(S·V·O·C·M) 색 표시, 종속절·수식 범위, 핵심 어휘, 글 속 의미, 문장별 문법, 불확실한 해석 표시, 중요 문장 별표 |
| 3. 핵심 문법 | 지문 전체에서 선별한 문법(원문·원리·해석·출제 가능성), 분류별 필터 |
| 4. 중요 어휘 | 품사·문맥상 의미·기본 의미·유의어·반의어·파생어·중요도 표, 단어 카드(플래시카드), 암기 체크, 미암기 단어만 보기 |
| 5. 출제 포인트 | 예상 출제 유형, 핵심 문장, 빈칸 후보, 어법 변형 구문, 연결어, 지시어 지칭 대상, 전환 지점, 혼동 요소 (상·중·하 중요도, '예상'임을 명시) |
| 6. 예상 문제 | 객관식·빈칸·어법·어휘·순서·삽입·서술형·영작. 제출하거나 '정답 확인'을 눌러야 정답과 해설 공개, 자기 채점, 다시 풀기, 유형·문항 수를 골라 재생성 |

학습 관리: 제목 수정, 저장·삭제, 최근 학습 순 목록, 검색, 즐겨찾기, 학습 완료, 복습 기록(1·3·7·14·30일 간격 복습 권장), 복습 필요 표시, 전체 단어장, JSON 백업/복원, 인쇄/PDF.

## 실행

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
# http://localhost:3000
```

Node.js 20 이상이 필요합니다.

### 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | (필수) | Claude API 키. 서버에만 있고 브라우저로 전달되지 않습니다. 없으면 분석을 실행하지 않고 안내만 표시합니다. |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | 분석 모델 |
| `ANALYSIS_EFFORT` | `high` | `low` / `medium` / `high` / `xhigh` / `max` |
| `DISABLE_REFUSAL_FALLBACK` | (미설정) | `1`이면 서버 측 거절 대체 모델(fallbacks) 기능을 끕니다 |
| `PORT` | `3000` | 서버 포트 |
| `MAX_PASSAGE_CHARS` | `12000` | 지문 최대 글자 수 |
| `RATE_LIMIT_PER_10MIN` | `80` | IP당 10분간 AI 호출 수 제한 |
| `SYNC_DATA_DIR` | `./data/sync` | 클라우드 동기화 데이터 저장 위치 |
| `TRUST_PROXY` | (미설정) | 리버스 프록시 뒤에서 실행하면 `1` |

## 구조

```
server/
  index.js       Express 서버: 정적 파일, 분석 API(NDJSON 스트림 + keep-alive), 동기화 API, 보안 헤더, 요청 제한
  ai.js          Claude 호출 (스트리밍, 구조화 출력 JSON Schema, 오류 → 한국어 안내)
  prompts.js     시스템 프롬프트(정확성 원칙)와 작업별 지시
  schemas.js     분석 결과 JSON Schema
  sync-store.js  동기화 코드 기반 저장소 (낙관적 동시성 제어)
public/
  index.html, css/app.css   화면과 디자인 시스템 (라이트/다크, 반응형)
  js/split.js     문장 분리기 (서버·브라우저 공용 — 문장 번호 일치 보장)
  js/jobs.js      분석 작업 분할·병렬 실행·재시도·취소
  js/store.js     IndexedDB 저장(대체: localStorage) + 클라우드 동기화
  js/views/       지문 화면 6개 탭, 논리 관계도
test/             문장 분리기 테스트 (npm test)
```

### 분석 방식

하나의 지문은 여러 AI 호출로 나뉘어 병렬로 실행됩니다: ① 전체 분석·구조·관계, ② 문법·어휘·출제 포인트, ③ 문장별 상세 분석(3~4문장씩 묶음), ④ 예상 문제. 끝난 항목부터 화면에 표시되고, 실패한 항목만 다시 시도할 수 있습니다. 새로고침으로 중단된 작업은 '남은 항목 분석'으로 이어서 실행합니다. 모든 결과는 JSON Schema로 형식을 고정하고, 문장 번호는 서버가 직접 분리한 기준을 사용해 모든 문장이 빠짐없이 분석되도록 확인합니다(누락 시 해당 문장만 재시도).

### 데이터 저장

- 기본: 브라우저 IndexedDB에 자동 저장 (새로고침·브라우저 종료 후에도 유지)
- 선택: 설정 화면에서 동기화 코드를 만들면 서버(`SYNC_DATA_DIR`)에 저장되어 다른 기기에서 같은 코드로 이어서 학습할 수 있습니다. 코드는 비밀번호처럼 취급하세요. 서버에는 코드의 SHA-256 해시가 파일 이름으로 쓰입니다.
- 클라우드 저장을 운영 환경에서 쓰려면 `SYNC_DATA_DIR`가 영구 디스크에 있어야 합니다.
